## 字段含义

以下为本项目菜单表（sys_menu）的实际字段模型，与上游 vue-pure-admin 模板的前端字段（`menuType` 0/1/2/3、`parentId`、`rank` 等）不同。

| 字段      | 说明                                                                   |
| :-------- | :--------------------------------------------------------------------- |
| `type`    | 菜单类型（`D`代表目录、`M`代表菜单、`B`代表按钮）                       |
| `pid`     | 上级菜单 ID（顶级菜单为 `"0"`，后端序列化为字符串防精度丢失）            |
| `title`   | 菜单名称                                                               |
| `path`    | 路由路径（以 `/` 开头，仅含字母、数字、`-`、`_`）                        |
| `component` | 组件路径（前端视图文件路径；按钮类型无组件路径）                       |
| `sort`    | 菜单排序（数值越小越靠前）                                             |
| `icon`    | 菜单图标                                                               |
| `perms`   | 权限标识（按钮级权限设置，格式如 `system:menu:insert`）                 |
| `status`  | 状态（`0`启用、`1`禁用）                                               |
| `hidden`  | 是否隐藏（`0`显示、`1`隐藏）                                           |
| `builtin` | 是否内置（内置菜单不可修改、删除，前端开关与勾选同样禁用）               |
| `remark`  | 备注                                                                   |
